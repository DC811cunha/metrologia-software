# Backend Node/Express (legado)

Este diretório contém o backend original em Node.js + TypeScript + Express, definido pelo
ADR-001 (`docs/adr/ADR-001-stack-tecnologica.md`).

Ele foi descontinuado e substituído por um backend FastAPI/Python conforme o
ADR-003 (`docs/adr/ADR-003-stack-backend-fastapi.md`), durante o planejamento da feature
`001-softmeter-plataforma-mvp`. O código é mantido aqui apenas como referência histórica; o
histórico completo também está disponível via `git log` no caminho original `src/backend/`.
